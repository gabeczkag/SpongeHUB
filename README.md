# SpongeHUB

Murder Mystery 2 Script Hub for Roblox

## Features

- **Aimbot** — FOV-based targeting with smoothing, silent aim, role-based filtering
- **ESP** — Box, Name, Role, Distance, Health Bar, Tracer with color-coded roles
- **Anti-Cheat Spoof** — Kick protection, remote hook blocking, heartbeat spoofing
- **Misc** — Speed Hack, NoClip, Infinite Jump, Flick Knife

## Controls

| Key | Action |
|-----|--------|
| `RightControl` | Toggle GUI |

## Requirements

- Roblox exploit executor with `Drawing` API support
- Compatible executors: Synapse X, Script-Ware, Fluxus, etc.

## Installation

1. Copy the contents of `scripts/mm2/Script.luau`
2. Paste into your executor
3. Execute while in [Murder Mystery 2](https://www.roblox.com/games/142823291)

Or use `loader.lua` with a web-hosted script URL.

## Structure

```
SpongeHUB/
├── loader.lua              # Game loader
├── scripts/
│   └── mm2/
│       └── Script.luau     # MM2 full script
```
